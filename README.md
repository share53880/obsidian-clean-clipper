> 📝 **100% Offline, Privacy-First HTML to Clean Markdown Clipper Plugin directly inside Obsidian.**

Tired of pasting web articles into Obsidian only to get messy nested `<div>`, broken styling, and tracking scripts? **Clean Clipper Pro** cleans and translates clipboard HTML into clean, noise-free Markdown with a single hotkey or ribbon click.

---

## 🌟 Key Features

- ✂️ **One-Click Noise Stripping**: Automatically removes header, footer, nav, script, style, and tracking tags.
- 📑 **Faithful Markdown Syntax**: Retains H1-H4 headings, bold, italics, inline code, fenced code blocks, and blockquotes.
- 🔒 **100% Offline & Local**: Zero cloud dependencies. Your notes and clipboard data never leave your local vault.
- ☕ **Native Funding Support**: Directly integrated with Buy Me a Coffee and Afdian via official `fundingUrl`.

---

## 🚀 How to Install & Use

### Method 1: Via Obsidian Community Plugins (Recommended)
1. Open Obsidian -> `Settings` -> `Community plugins`.
2. Disable Safe Mode, click `Browse`, search for **Clean Clipper Pro**.
3. Click `Install`, then `Enable`.

### Method 2: Manual Installation
1. Download `main.js` and `manifest.json` from [Releases](https://github.com/share53880/obsidian-clean-clipper/releases).
2. Copy them into your vault at: `<Vault>/.obsidian/plugins/obsidian-clean-clipper/`.
3. Reload Obsidian and enable the plugin!
